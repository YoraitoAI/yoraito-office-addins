# Contributing

Thanks for helping. This project is alpha and moves quickly.

## Before you start

Open an issue for anything large or structural. Small fixes and docs can go straight to a
pull request.

## Pull requests

- Keep one change per pull request.
- Add or update tests where the repository has them. See the README for the test command.
- Run the tests and the linter before you push.
- Sign off your commits with `git commit -s`. We use the Developer Certificate of Origin
  and do not require a CLA.
- By contributing, you agree that your contribution is licensed under the repository's MIT
  licence.

## Security

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Conduct

Be direct, be kind, and assume good faith. Disagreement about code is fine. Personal
attacks are not.
